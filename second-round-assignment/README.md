# MultiGenesys E-Commerce Backend System

## Architecture
Microservices-based backend with:
- auth-service (JWT authentication)
- order-service (product, cart, order, payment)

## Tech Stack
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- MySQL

## Features
- User authentication & authorization
- Product management
- Cart management
- Order processing
- Payment integration (Stripe/PayPal)

## How to Run
1. Run auth-service
2. Run order-service
3. Use Postman for API testing
